# Agent Instructions

## Package Managers

- Node: **npm** — `npm install`, `npm run dev`, `npm run build`
- Python: `python -m pip install -r scripts/requirements-directory.txt`

## File-Scoped Commands

| Task | Command |
|---|---|
| Test Corporate sync | `python -m unittest tests.test_sync_corporate_education -v` |
| Test Brightspace sync | `python -m unittest tests.test_sync_brightspace_tutorials -v` |
| Check Corporate drift | `python scripts/sync_corporate_education.py --check` |
| Check Brightspace drift | `python scripts/sync_brightspace_tutorials.py --check` |
| Compile a scraper | `python -m py_compile scripts/<scraper>.py` |

## Key Conventions

- Keep standalone Ellucian pages in `Pages/`.
- Keep web scrapers in `scripts/`, snapshots in `docs/`, tests in `tests/`, and schedules in `.github/workflows/`.
- Treat content between matching `AUTO-SYNC` comments as generated; change its renderer or scraper instead of hand-editing it.
- Preserve embedded HTML as the runtime fallback when a public JSON request fails.
- Runtime loaders fetch snapshots from the public repository `main` branch with cache busting.
- Normalize relative SFSC links to absolute HTTPS URLs.
- Validate source structure and minimum/maximum result counts before writing output.
- A second successful sync must be idempotent.
- Keep public snapshots free of credentials, tokens, student data, non-public employee data, and regulated information.
- See `docs/AUTOMATED_CONTENT_SYNCS.md` for architecture and operations.
- See `docs/ELLUCIAN_REPUBLISH_CHECKLIST.md` for the one-time deployment procedure.

## Generated Assets

- `docs/corporate_education.json` is generated by `scripts/sync_corporate_education.py`.
- `docs/brightspace_tutorials.json` is generated by `scripts/sync_brightspace_tutorials.py`.
- Do not manually edit generated JSON snapshots.
